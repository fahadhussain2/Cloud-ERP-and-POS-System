# Cloud ERP + Offline POS

[![CI](https://github.com/fahadhussain2/Cloud-ERP-and-POS-System/actions/workflows/ci.yml/badge.svg?branch=staging)](https://github.com/fahadhussain2/Cloud-ERP-and-POS-System/actions/workflows/ci.yml)

Multi-tenant cloud ERP with an offline-first, keyboard-driven POS for retail shops. First tenant: Delux Autos, Karachi.

- **How to work in this repo:** [CLAUDE.md](CLAUDE.md) (commands and rules) and [docs/07-DELIVERY-PROCESS.md](docs/07-DELIVERY-PROCESS.md)
- **What we build:** [docs/](docs/) (PRD, architecture, data model, posting rules, migration, decision log) and [docs/modules/](docs/modules/README.md)
- **Quick start:** Node 24 LTS and pnpm 11, then `pnpm install` and `pnpm check`
